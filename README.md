# Titanic Passenger Survival Study
# Inter ID: CITS9173
## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic passenger dataset to understand the factors associated with passenger survival.

The analysis focuses on passenger demographics, passenger class, age, gender, fare, and family characteristics.

## Objectives

- Analyze the overall survival rate.
- Study survival differences between male and female passengers.
- Analyze survival across different passenger classes.
- Study the relationship between age and survival.
- Analyze the relationship between fare and survival.
- Examine the effect of family size on survival.
- Identify important patterns and relationships in the dataset.
